# CAD 评分代码

- [v1 回归评分](cad_case_v1/README.md)：几何、尺寸比例、原生标注、STEP 与固定夹具检查。
- [v2 BenchCAD 风格评分](cad_case_v2_benchcad/README.md)：执行提交代码后计算两个零件的体素 IoU，工程检查及夹具复现另报。

两套均附原题输入、冻结参考、尺寸规格、依赖清单和自检程序。推荐采用 v2；保留 v1 用于复现早期规则。models 是最新制图成果，benchmark/reference 是评分冻结答案，两者用途不同。自检与报告是运行时生成的文件，不作为上传内容。输入 PDF 的权利归原作者，本私有仓库用于复现已有练习；第三方评分器保留原许可证。

本包不含 API 密钥或 OpenCode 会话数据；本次只验证评分代码，不重跑付费模型测评。
