# 被测系统任务

根据 inputs 中两份 PDF 创建 DXF，再创建零件 STEP，并按给定夹具设计参考创建单零件、多实体夹具 STEP。

NAAMS ASP230：60×50×3 mm，两个 Ø10.5 通孔，平面中心 (30,10)、(30,40)。对称支架：源图 Exercise 2.1M（PDF 第 35 页），外形 120×60 mm，厚度按练习设计取 6 mm；四个 Ø18 通孔中心 (-45,15)、(-20,40)、(20,40)、(45,15)。源图其余轮廓尺寸必须遵守。

毫米，1:1；圆和圆弧采用原生实体；标注采用原生 DIMENSION，头部及全部样式 dimlfac=1，尺寸文字保持测量占位符，不用纯文字掩盖比例。保留 OUTLINE、CENTER、DIMENSIONS、NOTES 分层；垫板还需 HIDDEN 层。箭头需实心、方向与端点正确，标注不重叠；这些视觉要求在 v1 中人工评审。

固定夹具复现任务的输入是 inputs 下对应的 fixture_design.step，独立测试此任务时提供该文件。此文件用于定义形状及相对位置，不是要求从 PDF 推理出唯一夹具设计。将其保存为单产品、多实体 STEP，不增加毛坯参考实体，不输出装配或装夹参考版。若评测自主夹具设计，不使用此版固定几何评分。

按 README 的 6 个路径提交成果。不得读取或修改评测端 reference、spec、脚本与报告。生成用时和是否成功可另行记录；本评测器只评文件成果。
